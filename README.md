# Class Facts Web App

## Author
Griffin Shewbart — [gshew24](https://github.com/gshew24)

## Description
This project dynamically displays fun facts collected from classmates using JavaScript, HTML, and CSS. It allows searching, sorting, and liking facts. The app is deployed via GitHub Pages.

## Features
- Search facts by keyword
- Sort alphabetically, reverse, or randomly
- ❤️ Like and ❌ Unlike facts

## Folder Structure
- `scripts/` - JavaScript files (`facts.js`, `app.js`)
- `styles/` - CSS styling
- `pages/` - Wireframe layout
- `README.md`, `index.html` in root
